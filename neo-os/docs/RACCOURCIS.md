# Raccourcis clavier de Néo OS

La touche **Windows** est la touche au logo Windows (aussi appelée Super). Cette fiche est générée depuis `/usr/share/neo/raccourcis.tsv`, la même liste que celle appliquée à l'ouverture de session ; dans Néo OS : menu → Raccourcis clavier.

## Applications et session

| Touches | Action |
|---|---|
| <kbd>Ctrl + Maj + Échap</kbd> | Gestionnaire des tâches |
| <kbd>Ctrl + Alt + Suppr</kbd> | Menu de session : verrouiller, changer d'utilisateur, se déconnecter, redémarrer, éteindre |
| <kbd>Windows</kbd> | Menu des applications, avec recherche (tapez directement) |
| <kbd>Windows + E</kbd> | Gestionnaire de fichiers |
| <kbd>Windows + R</kbd> | Exécuter une commande |
| <kbd>Windows + I</kbd> | Paramètres |
| <kbd>Windows + L</kbd> | Verrouiller la session |
| <kbd>Windows + S</kbd> | Rechercher des fichiers |
| <kbd>Windows + Maj + S</kbd> | Capture d'une zone de l'écran |
| <kbd>Impr. écran</kbd> | Capture de tout l'écran |
| <kbd>Windows + T</kbd> | Terminal |
| <kbd>Ctrl + Alt + T</kbd> | Terminal |

## Fenêtres et bureaux

| Touches | Action |
|---|---|
| <kbd>Windows + D</kbd> | Afficher le bureau, puis restaurer les fenêtres |
| <kbd>Windows + ←</kbd> | Placer la fenêtre sur la moitié gauche |
| <kbd>Windows + →</kbd> | Placer la fenêtre sur la moitié droite |
| <kbd>Windows + ↑</kbd> | Agrandir la fenêtre (de nouveau : restaurer) |
| <kbd>Windows + ↓</kbd> | Réduire la fenêtre dans la barre des tâches |
| <kbd>Alt + Tab</kbd> | Passer à la fenêtre suivante |
| <kbd>Alt + Maj + Tab</kbd> | Revenir à la fenêtre précédente |
| <kbd>Alt + F4</kbd> | Fermer la fenêtre |
| <kbd>Ctrl + Windows + ←</kbd> | Bureau virtuel précédent |
| <kbd>Ctrl + Windows + →</kbd> | Bureau virtuel suivant |

## Fichiers et édition

| Touches | Action |
|---|---|
| <kbd>F2</kbd> | Renommer le fichier sélectionné |
| <kbd>Ctrl + C / Ctrl + X / Ctrl + V</kbd> | Copier / couper / coller |
| <kbd>Ctrl + Z / Ctrl + Y</kbd> | Annuler / rétablir |
| <kbd>Ctrl + A</kbd> | Tout sélectionner |
| <kbd>Suppr / Maj + Suppr</kbd> | Mettre à la corbeille / supprimer définitivement (avec confirmation) |
| <kbd>Ctrl + Maj + N</kbd> | Nouveau dossier |
| <kbd>Alt + Entrée</kbd> | Propriétés du fichier |
| <kbd>Ctrl + L</kbd> | Modifier la barre d'adresse |
| <kbd>Ctrl + F</kbd> | Rechercher dans le dossier |
| <kbd>Alt + ↑ / Alt + ← / Alt + →</kbd> | Dossier parent / précédent / suivant |
| <kbd>F5</kbd> | Actualiser |
| <kbd>Ctrl + 1 / Ctrl + 2 / Ctrl + 3</kbd> | Vue icônes / liste détaillée / liste compacte |
| <kbd>Ctrl + T / Ctrl + W</kbd> | Nouvel onglet / fermer l'onglet |
